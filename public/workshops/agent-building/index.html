2.1 · What an agent is

Stable

Most of what you need is not an agent

One call

you write the prompt

Classify, extract, summarise, rewrite. One request, one answer. Cheapest, fastest, easiest to test.

Workflow

your code picks the steps

Several calls wired together by code you wrote. Predictable. Each step can be tested alone.

Agent

the model picks the steps

The model decides which tool to call next, and when it is done. Flexible, and harder to predict.

Split taken from Anthropic, “Building effective agents” (Dec 2024) — still the best short read on this.

2.2 · The loop

Stable

The model asks. Your code acts.

The model never runs anything. It returns a tool_use block and stops. Your harness runs the tool, sends the result back, and calls the model again — until it stops asking.

Every round trip re-sends the whole transcript. Watch the context counter.

    2.3 · The loop, in code

    Stable

    Twenty lines, and you own every one

    A turn cap, so a confused model cannot loop forever. All tool results back in one message. Failures sent back as errors, not swallowed.

    Everything a framework adds sits somewhere in these lines.

    agent.py · anthropic SDK

    for turn in range(MAX_TURNS):
    resp = client.messages.create(
        model="claude-sonnet-5", max_tokens=16000,
        system=SYSTEM, tools=TOOLS, messages=messages)
    messages.append({"role": "assistant", "content": resp.content})

    if resp.stop_reason != "tool_use":
        break                        # end_turn or refusal

    results = []
    for block in resp.content:
        if block.type == "tool_use":
            out, failed = run_tool(block.name, block.input)
            results.append({"type": "tool_result",
                "tool_use_id": block.id,
                "content": out, "is_error": failed})
    messages.append({"role": "user", "content": results})
else:
    raise TurnLimit("agent did not finish")

    2.4 · Should you build one?

    Stable

    Four questions. One “no” and you stay simpler.

    Complexity

    Is it multi-step, and hard to spell out in advance? “Extract the title” is not.

    Value

    Is the outcome worth the extra latency and cost of a loop?

    Viability

    Can the model actually do this kind of task? Try it by hand in a chat first.

    Cost of error

    Can mistakes be caught and undone — tests, review, rollback, a human gate?

    Triage passes all fourbecause every write goes past a human
