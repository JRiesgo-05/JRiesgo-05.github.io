What I named, what it chose

Each prompt named a gap. None of them named the fix. The forms that worked came from the agent.

RoundI namedIt chose
one"how it works and why you did it"A four-step model of search, and a what-and-why card per change
two"visualization"A different diagram type for each change: flow, tree, queue, sequence, graph
three"story based", "tangible"A town metaphor, one map that grows with the story, an ID badge, a calendar of what happens next
