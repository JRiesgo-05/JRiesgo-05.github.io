One fix, four ways

The same small bug in a FastAPI app, done at each step from Copilot autocomplete to Claude Code desktop. Watch what I type, what the AI does and how many windows I touch.

The bug

A FastAPI app keeps HTML reports in reports/<name>/index.html. On the server, nginx serves them at /reports/<name>/. Locally, uvicorn app.main:app --reload returns 404 for the same URL, so I can't check a report before I ship it.

I write it, Copilot finishes lines

  1. Open the report in Chrome, see {"detail":"Not Found"}
  2. Search "fastapi staticfiles index.html 404"
  3. Read the Starlette docs, find html=True
  4. Edit the mount in app/main.py, Copilot fills the line
  5. Watch uvicorn reload in the VS Code terminal
  6. Back to Chrome, reload each report
6steps by me
4windows
