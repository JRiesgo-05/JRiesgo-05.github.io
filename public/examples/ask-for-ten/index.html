Example · Ask for ten, keep one

One slowdown, ten ways to explain it

The prompt

Explain why this job got slow in ten different ways, as one artifact with a tab for each: an analogy, a timeline, a simulator, a code walkthrough and so on. Use the same facts in every tab, and make each one visual first.

The facts: a nightly job asks the warehouse three questions. Before answering each one, the warehouse lists every file in the bucket, about 600,000, when the job only needs today's 30,000. Two fixes: read only today's folder, and ask once instead of three times.

The system, names and numbers here are made up. The shape of the problem and the ten ways are from the real page.

What I keep

Different readers pick different tabs. The analogy for someone outside the team, the waterfall for whoever asks what we save, the code walk for whoever reviews the fix. Two or three land. The rest were worth seeing once.
