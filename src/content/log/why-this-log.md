I use AI agents for almost everything I learn now. That makes learning fast, but it also makes it easy to forget. An answer that took ten seconds to get takes ten seconds to lose. So this year I am writing down what sticks.

## Learn through what you know

When I pick up something new, I don't ask for a generic explanation. I tell the agent what I already know: a project I shipped, a tool I understand, an analogy that works for me. Then I ask it to explain the new thing in those terms.

The first answer is never the one I keep. I edit it down, ruthlessly, until it fits in a few sentences I could say out loud. If I can't shorten it, I don't understand it yet.

## Principles over band-aids

A patch fixes today's bug. A principle fixes the next ten. When something breaks, I keep asking why until I reach a rule I can reuse, and that rule is what goes in this log.

## Change the angle

Code is one layer over the real job, which is shaping inputs into outcomes. Searching Google and asking an agent are the same act: moving information into my head. The agent just moves it faster.

Looking at a problem from one level up usually shows a simpler answer.
